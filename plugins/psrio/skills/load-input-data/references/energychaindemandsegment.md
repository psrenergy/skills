# EnergyChainDemandSegment

| Data | Description | Unit |
| :--- | :--- | :---: |

| `EnergyChainDemandSegment().hour` | Hourly demand volume | MW |

| `EnergyChainDemandSegment().cost` | Cost associated with the segment | $/MWh |
